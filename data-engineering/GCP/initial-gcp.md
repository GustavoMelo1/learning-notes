# GCP — Google Cloud

GCP é a plataforma de nuvem do Google. Ela oferece serviços para guardar arquivos, executar aplicações e analisar dados sem precisar manter um servidor próprio.

## Exemplo simples

Uma loja pode guardar um arquivo de vendas no **Cloud Storage** e usar o **BigQuery** para consultar essas vendas com SQL. Os dois são serviços do Google Cloud.
