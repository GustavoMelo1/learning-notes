# 08 - List

Listas são sequências ordenadas e **mutáveis** que guardam vários valores, com suporte a indexação e slicing.

## Exemplo

```python
my_list = ['a', 'b', 'c', 'd', 'e']

my_list.append('f')
print(my_list)

print(my_list[0:3])
```

```text
['a', 'b', 'c', 'd', 'e', 'f']
['a', 'b', 'c']
```
