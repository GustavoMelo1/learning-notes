# Set

Set remove duplicados automaticamente e permite adicionar novos elementos.

## Convertendo lista com duplicados

```python
print(set([1, 1, 1, 1, 2, 2, 2, 2, 3]))
```

```text
{1, 2, 3}
```

## Criando e modificando um set

```python
s = {1, 2, 3, 4, 5}
s.add(6)
print(s)
```

```text
{1, 2, 3, 4, 5, 6}
```
