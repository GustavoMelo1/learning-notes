# 01 - Variáveis

Variáveis são containers nomeados que guardam um valor (texto, número ou lógico) pra usar depois.

## Tipos básicos

```text
Texto (String)   → ex: nome
Inteiro (Int)    → ex: idade
Decimal (Float)  → ex: altura
Lógico (Boolean) → True/False, ex: detecção de fraude
```

## Exemplo

```python
dinheiro = 1250
porcentagem_taxa = 0.1

total_taxa_mes = dinheiro * porcentagem_taxa
imposto = total_taxa_mes
print(imposto)
```

```text
125.0
```

Operações matemáticas entre variáveis funcionam direto, sem precisar converter nada.
