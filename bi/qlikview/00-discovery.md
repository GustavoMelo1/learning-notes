# 00 - Discovery

Perguntas padrão antes de começar qualquer projeto no QlikView. Se o cliente já respondeu isso no email, meio caminho andado.

## 1. Quem é o cliente?
Entender o negócio, o setor, o tamanho da operação. Sem isso, nada faz sentido.

## 2. Quais perguntas o BI precisa responder?
O que o cliente quer saber? Exemplos:
- Qual região vendeu mais?
- Qual produto tem maior margem?
- A meta do mês foi batida?

## 3. Qual é o processo dele?
Entender como o negócio funciona do início ao fim antes de montar qualquer coisa.

## 4. Como o cliente quer visualizar as informações?
- Gráfico de barras, linha, tabela?
- Um dashboard geral ou por área?
- Quem vai usar: diretoria, operação, vendas?

## 5. Onde estão os dados?
- Excel, banco de dados, sistema ERP?
- Está tudo num lugar só ou espalhado?
- Os dados estão limpos ou precisam de tratamento?
